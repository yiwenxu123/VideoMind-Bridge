## 三、降级链速查（谁挂了降到哪）

| 故障场景 | 降级行为 |
|---|---|
| Mac VMB（:8787）挂 | video-content-extractor 直接走 ③④⑤⑥ 自有链（平台字幕API → yt-dlp+SenseVoice/whisper → 云ASR → 商业API），**不再有公网 REST 这一级**；ContentExtractor → local Defuddle（注意：B站 local 提取可能产出页面 UI 碎片，内容质量需检查，见 benchmark-decompose-assist skill） |
| 公网 REST | 该级已删除（2026-11-20 起 401，2026-11-24 复核仍是旧构建），排查时不要再去试 |
| VMB 内某平台提取器失效 | v2 Engine **8 个提取器**自动降级（bilibili / youtube / douyin / xiaohongshu / ytdlp / ytdlp_asr / tikhub / apify），免费优先于付费；ASR 后端（sensevoice / faster_whisper / dashscope / aliyun）是另一条链，不算提取器 |
| ASR 服务不可用 | 本地 SenseVoice → faster-whisper（零 Key）。SenseVoice 是否真可用由 `scripts/install_sensevoice.sh --check` 判定，2026-11-24 起 `/api/v1/capabilities` 会真探测解释器依赖 |

## 五、边界与禁区

- v1 Legacy：**服务层仍在**（CLI `--mode`、`/legacy` 页面、`/api/v1/tasks*`）；**桌面 GUI 与浏览器扩展已于 2026-11-24 下线**（commit `7f7c8e8`，`src/gui/`、`browser-extension/` 已删除）。真有下载需求直接用 yt-dlp，**不复活 v1**
- 新调用方接入走本机 REST `127.0.0.1:8787`（`/api/v1/extract`、`/api/v1/capabilities`、`/api/v1/comments`、`/api/v1/metrics`）；MCP 只有 **3 个工具**：`extract(url, mode, cost_tier, asr_language)` / `capabilities()` / `comments(url, limit, sort)`，且它依赖本机服务在跑——旧的 `prescreen_video` / `smart_extract` / `extract_video` / `archive_extract` 已全部移除，不要再照着写
- 采集合规：自动化巡检只用 RSS（不自动请求平台），见内容运营agent 10-10 采集合规定稿
