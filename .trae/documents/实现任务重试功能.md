## 问题分析

当前重试功能只有 UI 按钮，没有实际实现：
1. TaskItemWidget 没有保存 TaskInfo（url, mode, targets）
2. MainWindow._on_task_retry() 只显示提示框，没有实际重试逻辑

## 修复方案

### 1. 修改 TaskItemWidget (task_queue.py)
- 在 `__init__` 中保存 `task_info` 对象
- 添加 `get_task_info()` 方法返回任务信息

### 2. 修改 TaskQueueWidget (task_queue.py)
- 修改 `_on_task_retry()` 方法，获取任务的原始信息并转发
- 或者修改信号，同时传递 task_id 和 task_info

### 3. 修改 MainWindow (main_window.py)
- 修改 `_on_task_retry()` 方法：
  1. 从 task_queue 获取任务的 url, mode, targets
  2. 重置任务状态为 PENDING
  3. 调用 `_start_processing_task()` 重新启动任务

### 4. 代码变更

**TaskItemWidget 修改:**
```python
def __init__(self, task_info: TaskInfo, parent=None):
    super().__init__(parent)
    self.task_id = task_info.id
    self.task_info = task_info  # 保存完整信息
    self._setup_ui(task_info)

def get_task_info(self) -> TaskInfo:
    """获取任务信息"""
    return self.task_info
```

**TaskQueueWidget 修改:**
```python
def get_task_info(self, task_id: str) -> Optional[TaskInfo]:
    """获取任务信息"""
    if task_id in self.tasks:
        return self.tasks[task_id].get_task_info()
    return None

def _on_task_retry(self, task_id: str):
    """任务重试"""
    task_info = self.get_task_info(task_id)
    if task_info:
        self.task_retry.emit(task_id, task_info.url, task_info.mode, task_info.targets)
```

**MainWindow 修改:**
```python
def _on_task_retry(self, task_id: str, url: str, mode: ProcessingMode, targets: list):
    """任务重试"""
    # 重置任务状态
    self.task_queue.update_task_status(task_id, TaskStatus.PENDING, "等待中")
    self.task_queue.update_task_progress(task_id, 0, "等待中")
    
    # 重新启动任务
    self._start_processing_task(task_id, url, mode, targets)
    self.status_bar.showMessage(f"重试任务: {task_id}")
```

## 预期效果
- 点击失败任务的"重试"按钮可以重新执行任务
- 任务状态重置为 PENDING，进度重置为 0
- 使用原始任务的 url, mode, targets 重新启动处理
