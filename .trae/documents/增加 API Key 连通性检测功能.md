## 功能目标
在 AI 配置界面增加 "测试连接" 按钮，让用户在配置 API Key 后能立即验证连通性。

## 实现方案

### 1. 界面修改 (ai_config.py)
- 在 API Key 输入框旁边添加 "测试连接" 按钮
- 添加状态标签显示测试结果
- 添加 `_on_test_connection` 方法处理点击事件

### 2. 服务层修改 (ai_service.py)
- 添加 `test_connection()` 方法
- 发送简单的测试请求验证 API Key
- 返回布尔值和错误信息

### 3. 界面布局
```
API Key: [输入框...] [测试连接按钮]
         [状态图标] 连接成功 / 连接失败: 错误信息
```

## 预期效果
- 用户配置 API Key 后可立即验证
- 避免在处理视频时才发现配置错误
- 提升用户体验和排查效率

## 工作量
- 约 30-50 行代码
- 修改 2 个文件
- 测试简单
