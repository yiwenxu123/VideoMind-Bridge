## 改进计划

### 1. 重新设计文件输出策略
**核心思路**：无论用户选择哪些导出目标，视频/音频文件始终保存在本地文件夹，其他目标（Obsidian）通过链接引用本地文件。

**具体实现**：
1. **本地文件夹**（始终创建，即使未选择）：
   - 视频文件 (mp4)
   - 音频文件 (m4a)
   - 字幕文件 (srt)
   - 转录文本 (txt)
   - Markdown 笔记 (md)
   - player.html（视频播放器）
   - highlights.json

2. **Obsidian**（仅创建 Markdown）：
   - 只生成 `.md` 文件
   - 时间轴链接指向本地视频文件（使用绝对路径或相对路径）
   - 使用 Media Extended 插件支持的格式

### 2. 修复时间轴跳转问题
将 Obsidian Markdown 中的链接从 `[[player.html|00:01:30]]` 改为链接到本地视频文件：
```markdown
- [[../../Downloads/VideoMind/2026-01-30/视频标题/视频标题.mp4#t=90|00:01:30]] - 内容描述
```

### 3. 优化导出逻辑
修改 `_process_full` 方法：
- 始终将视频/音频保存到本地文件夹
- 如果选择了 Obsidian，生成 Markdown 并链接到本地视频
- 如果选择了本地文件夹，复制文件到指定位置

### 4. 用户界面优化
在"输出目标"区域添加说明：
> 注：视频文件始终保存在本地文件夹，Obsidian 笔记通过链接引用本地视频，避免重复存储。
