## 问题分析

### 根本原因
1. **lambda 闭包问题**: Python lambda 捕获的是变量引用，不是值。当信号触发时，使用的是变量的最终值。
2. **参数不匹配**: `task_failed = Signal(str, str)` 发出两个参数，但 lambda 只接收一个参数。

### 当前代码
```python
worker.task_failed.connect(lambda error: self._on_task_failed(task_id, url, error))
```

问题：
- lambda 只接收 `error` 一个参数
- 但信号发出 `(task_id, error_message)` 两个参数
- 使用外部 `task_id` 和 `url` 变量，存在闭包问题

### 修复方案

**方案 1: 使用默认参数捕获当前值（推荐）**
```python
worker.task_failed.connect(
    lambda tid, err, url=url: self._on_task_failed(tid, url, err)
)
```

**方案 2: 使用 functools.partial**
```python
from functools import partial
worker.task_failed.connect(
    partial(self._on_task_failed, url=url)
)
# 修改 _on_task_failed 签名
def _on_task_failed(self, task_id: str, error_message: str, url: str = None):
```

**方案 3: 使用闭包函数**
```python
def make_failed_handler(tid, url):
    def handler(task_id, error):
        self._on_task_failed(task_id, url, error)
    return handler

worker.task_failed.connect(make_failed_handler(task_id, url))
```

我推荐**方案 1**，因为它最简单且不需要修改 `_on_task_failed` 的签名。
