## 问题分析

### 当前问题
1. **"配置状态"占用空间过大** - 显示3行状态信息 + 提示文字，占用过多垂直空间
2. **状态显示不准确** - Obsidian 明明设置了路径却显示"未启用"，可能是 `enabled` 字段为 false
3. **模式不匹配** - "仅下载"和"转录存档"模式下不需要 API Key 和 Obsidian，显示这些信息显得累赘

### 优化方案

#### 方案一：简化配置提示（推荐）
**思路**：将庞大的"配置状态"分组框改为简洁的提示栏

**具体实现**：
1. **移除"配置状态"分组框**
2. **在标题下方添加简洁提示栏**：
   ```
   💡 首次使用？请先配置 API Key 和导出路径 → [前往设置]
   ```
3. **根据模式动态显示提示**：
   - **完整处理模式**：如果 API Key 未配置，显示警告提示
   - **仅下载/转录模式**：不显示 API Key 相关提示
4. **添加"前往设置"快捷按钮**，点击直接打开设置对话框

**优点**：
- 占用空间小（只有一行）
- 只在需要时提示（智能）
- 有明确的操作指引

---

#### 方案二：整合到模式选择中
**思路**：在每个模式的描述中说明需要的配置

**具体实现**：
1. **修改模式卡片描述**：
   - 完整处理："需要：API Key、本地文件夹、Obsidian（可选）"
   - 仅下载："需要：本地文件夹"
   - 转录存档："需要：本地文件夹"
2. **在模式选择下方添加统一提示**：
   ```
   💡 配置不足？点击这里进行设置 →
   ```

**优点**：
- 用户在选择模式时就了解需要什么配置
- 配置提示与模式选择关联性强

---

#### 方案三：状态栏提示
**思路**：利用底部状态栏显示配置状态

**具体实现**：
1. **状态栏左侧显示配置状态**：
   - "⚙️ 未配置 API Key"
   - "✅ 配置完整"
2. **点击状态栏打开设置**

**优点**：
- 完全不占用主界面空间
- 持续显示状态

---

## 我的建议

**采用方案一（简化配置提示）**，因为：
1. 最简洁，不占用过多空间
2. 智能提示，只在需要时显示
3. 有明确的操作按钮，用户体验好
4. 容易实现，改动小
