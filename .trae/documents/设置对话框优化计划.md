## 问题分析与优化计划

### 问题 1: 设置对话框第二次无法打开
**原因分析**: 
- 对话框可能是单例模式，第一次关闭后实例未正确销毁
- 或者对话框被设置为模态，但关闭逻辑有问题

**解决方案**:
- 每次打开时创建新实例，不缓存对话框对象
- 确保对话框关闭时正确销毁

### 问题 2: UI 优化
**当前问题**:
- 输入框太短，不美观
- API Key 输入框和显示按钮布局不合理
- 路径输入框没有与浏览按钮水平排列
- 缺少温度值显示

**优化方案**:
1. **增大输入框宽度**: 设置最小宽度 300px
2. **优化 API Key 布局**: 输入框和显示按钮水平排列
3. **优化路径输入**: 输入框和浏览按钮水平排列
4. **添加温度值显示**: 滑块旁边显示当前值
5. **统一间距和边距**: 更美观的留白
6. **添加说明文字**: 帮助用户理解配置项

### 问题 3: 首页配置 UI 去重
**当前状态**:
- 首页有 `AIConfigWidget` 和 `TargetSelector`
- 设置对话框有重复的配置项

**优化方案**:
1. **保留首页必要的快捷配置**:
   - AI 引擎选择（下拉框）
   - 导出目标选择（复选框）
   - 其他配置放入设置对话框

2. **或者完全移除首页配置**:
   - 首页只保留核心功能（URL输入、模式选择、开始按钮）
   - 所有配置都通过设置对话框管理
   - 在首页添加"打开设置"快捷按钮

**推荐方案**: 方案 2（完全移除首页配置，保持首页简洁）
