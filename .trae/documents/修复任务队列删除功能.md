## 问题分析

1. **已完成任务无法删除**: `TaskItemWidget._on_action_clicked()` 方法中，点击"删除"按钮时没有发出信号
2. **已取消任务无法删除**: 同样的问题，CANCELLED 状态也显示"删除"按钮但没有信号处理
3. **缺少删除信号**: `TaskQueueWidget` 没有 `task_deleted` 信号

## 修复方案

### 1. 修改 TaskItemWidget (task_queue.py)
- 添加 `delete_clicked = Signal(str)` 信号
- 在 `_on_action_clicked()` 中处理"删除"按钮点击，发出 `delete_clicked` 信号

### 2. 修改 TaskQueueWidget (task_queue.py)
- 添加 `task_deleted = Signal(str)` 信号
- 在 `add_task()` 中连接 `task_widget.delete_clicked` 信号到 `_on_task_delete` 方法
- 添加 `_on_task_delete(task_id)` 方法，调用 `remove_task(task_id)`
- 修改 `_on_clear_completed()` 方法，同时处理 COMPLETED 和 CANCELLED 状态的任务

### 3. 代码变更

**TaskItemWidget 修改:**
```python
# 添加信号
delete_clicked = Signal(str)  # 任务ID

# 修改 _on_action_clicked 方法
def _on_action_clicked(self):
    text = self.action_button.text()
    if text == "取消":
        self.cancel_clicked.emit(self.task_id)
    elif text == "重试":
        self.retry_clicked.emit(self.task_id)
    elif text == "删除":
        self.delete_clicked.emit(self.task_id)
```

**TaskQueueWidget 修改:**
```python
# 添加信号
task_deleted = Signal(str)  # 任务ID

# 修改 add_task 方法，连接删除信号
task_widget.delete_clicked.connect(self._on_task_delete)

# 添加删除处理方法
def _on_task_delete(self, task_id: str):
    self.task_deleted.emit(task_id)
    self.remove_task(task_id)

# 修改 _on_clear_completed，处理 CANCELLED 状态
def _on_clear_completed(self):
    to_remove = []
    for task_id, task_widget in self.tasks.items():
        text = task_widget.action_button.text()
        if text == "删除":  # 包括 COMPLETED 和 CANCELLED
            to_remove.append(task_id)
    for task_id in to_remove:
        self.remove_task(task_id)
```

## 预期效果
- 点击已完成任务的"删除"按钮可以删除任务
- 点击已取消任务的"删除"按钮可以删除任务
- "清空已完成"按钮可以清空所有已完成和已取消的任务
