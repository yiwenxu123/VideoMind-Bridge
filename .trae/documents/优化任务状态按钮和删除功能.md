## 问题分析

1. **取消任务后显示"删除"按钮是正确的**，因为 CANCELLED 状态在 `else` 分支中
2. **失败任务只有"重试"没有"删除"**，用户无法删除失败的任务
3. **取消的任务无法重试**，只能删除

## 优化方案

### 方案: 为所有非运行中任务提供"删除"功能

每个任务项应该有两个操作：
- 主操作按钮（取消/重试）
- 删除按钮（始终显示，或在特定状态下显示）

但考虑到界面简洁性，更好的方案是：

**修改 `_update_button_state` 逻辑：**
- 运行中任务 → "取消"按钮
- 失败任务 → "重试"按钮 + 支持删除（通过其他方式）
- 已完成/已取消 → "删除"按钮

**更简单的方案：**
为所有非运行中的任务（FAILED, COMPLETED, CANCELLED）都显示"删除"按钮，失败任务如果需要重试，可以通过重新添加任务来实现。

但这样不够友好。最佳方案是：

### 具体修改

**1. 修改 TaskItemWidget 添加删除按钮**
在任务项右侧添加一个"×"删除按钮，始终可见或仅在非运行状态可见。

**2. 修改按钮状态逻辑**
```python
def _update_button_state(self, status: TaskStatus):
    if status in [运行中状态]:
        self.action_button.setText("取消")
    elif status == TaskStatus.FAILED:
        self.action_button.setText("重试")
        self.delete_button.setVisible(True)  # 显示删除按钮
    else:
        self.action_button.setText("删除")
```

**3. 或者简化方案**
保持当前逻辑，但确保：
- FAILED → "重试"（同时支持删除）
- CANCELLED → "删除"（如果需要重试，用户需要重新添加任务）
- COMPLETED → "删除"

考虑到实现复杂度，我建议采用**简化方案**：

### 简化方案实现

**修改 TaskItemWidget：**
1. 在 `_setup_ui` 中添加一个删除按钮（×），放在操作按钮旁边
2. 删除按钮默认隐藏，在非运行状态显示
3. 点击删除按钮直接删除任务

**代码变更：**

```python
# TaskItemWidget._setup_ui 中添加删除按钮
self.delete_button = QPushButton("×")
self.delete_button.setMaximumWidth(30)
self.delete_button.clicked.connect(self._on_delete_clicked)
header_layout.addWidget(self.delete_button)

# _update_button_state 中控制删除按钮可见性
def _update_button_state(self, status: TaskStatus):
    if status in [运行中状态]:
        self.action_button.setText("取消")
        self.delete_button.setVisible(False)
    elif status == TaskStatus.FAILED:
        self.action_button.setText("重试")
        self.delete_button.setVisible(True)
    else:
        self.action_button.setText("删除")
        self.delete_button.setVisible(False)  # 已有删除按钮

# 添加删除处理方法
def _on_delete_clicked(self):
    self.delete_clicked.emit(self.task_id)
```

这样：
- 运行中任务：取消按钮，无删除按钮
- 失败任务：重试按钮 + 删除按钮（×）
- 已完成/已取消：删除按钮（主按钮）

## 预期效果
- 失败任务可以重试或删除
- 取消的任务可以删除
- 已完成的任务可以删除
